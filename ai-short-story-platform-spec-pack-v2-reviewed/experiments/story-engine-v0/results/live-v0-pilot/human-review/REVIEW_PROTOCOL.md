# Blind paired review protocol

For each row in `review-form.csv`, read Candidate A and Candidate B without
using the machine summary. Score each dimension from 1 (poor) to 5 (strong),
then select the preferred candidate or `tie`.

Dimensions: coherence, engagement, character consistency, ending/payoff,
TTS readability, and repetition fatigue. The machine mapping between candidate
numbers and system variants is kept outside this human-facing form.
